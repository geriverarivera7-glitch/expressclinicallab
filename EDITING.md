# Editing Guide — Express Clinical Lab Website

This is an editable source code project, not just a static export.

## Quick Start

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173/`.

Before publishing:

```bash
npm run lint
npm run build
```

## Common Edits

- Text: edit `src/locales/es/common.json` and `src/locales/en/common.json`.
- Homepage image: replace `src/assets/home-hero-care.jpg`.
- Logo: replace files in `src/assets/logo*`.
- Colors: edit `tailwind.config.js` and use `BRAND.md` as reference.
- Routes: edit `src/App.tsx`.
- Header/footer links: edit `src/components/Header.tsx` and `src/components/Footer.tsx`.
- Forms: submit handlers live in `src/pages/Contact.tsx`, `src/pages/AtHomeService.tsx`, and `src/pages/ForBusinesses.tsx`.

## Structure

```text
src/
  assets/       Logos and images
  components/   Shared UI
  locales/      Spanish and English copy
  pages/        Website pages
  App.tsx       Routes
```

Do not edit `dist/`; it is generated by `npm run build`. Do not commit `node_modules/`; dependencies are restored with `npm install`.
